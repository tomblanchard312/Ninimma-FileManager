Ninimma 0.1.6 synchronizes shared file-management features with FileExplorer while retaining Ninimma's own branding and installers.

- Add “Open file location in new tab” to search results. The new tab opens the containing folder and selects the result.
- Retain the working system clipboard shortcuts and opt-in default file manager controls from 0.1.5.
- Complete Lucide/Feather license distribution in the legacy Windows ZIP builder, with tests for ZIP contents and per-user notice installation.

The Ninimma Flatpak is attached to this release once its build, installation smoke test, checksums and GitHub artifact attestations have been verified. Restart Ninimma after updating.

Native packages and checksum files are verified with GitHub artifact attestations. Windows and macOS installers are unsigned; attestations provide build provenance, not OS code signing.
