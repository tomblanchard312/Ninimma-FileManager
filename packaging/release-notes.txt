Ninimma 0.1.8 searches pictures by what they show, matches filename words exactly, and sorts those results.

- Picture search runs while the text index is still catching up, and a photo does not wait until its text has been read.
- Photos and text are queued again when their saved vectors are missing.
- A search word matches a whole filename word, including a simple plural, so it no longer matches a longer word that only contains those letters.
- A picture query ranks photos by what they show above files that only match the name.
- Search results follow the Sort control: name, date modified, type, and size, including the column headers.

The Ninimma Flatpak is attached after its build, installation smoke test, checksums and GitHub artifact attestations are verified. Restart Ninimma after updating.

Native installers and checksum files include GitHub artifact attestations. Windows and macOS installers remain unsigned; attestations establish build provenance rather than OS code signing.
